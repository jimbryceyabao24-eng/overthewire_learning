# OverTheWire Bandit – Learning Journal (Levels 1–5)

## Introduction

This journal documents my cybersecurity learning journey through the OverTheWire Bandit wargame, focusing on Levels 1 to 5.

Throughout these challenges, I explored Linux commands, file management, hidden files, special characters, and file identification.

As a beginner in cybersecurity, I wanted to improve my understanding of Linux environments and develop practical problem-solving skills through hands-on exercises.

## Learning Objectives

- Understand basic Linux terminal commands.
- Learn how to navigate files and directories.
- Identify and access files with unusual filenames.
- Discover hidden files in Linux directories.
- Recognize different file types.
- Develop troubleshooting and logical thinking skills.

## Tools and Commands

Some of the Linux commands I practiced:

- `ls` – List directory contents.
- `ls -la` – Display all files, including hidden files.
- `pwd` – Display the current directory.
- `cd` – Change directories.
- `cat` – Display file contents.
- `file` – Identify file types.
- `find` – Search for files and directories.
- `./` – Refer to a file in the current directory.
